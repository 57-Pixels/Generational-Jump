# Economy and Industrial Base

> **Status:** working numbers for mini-US-scale **Veldara**. Rough costs per program still live in `data/costs.csv`.

## National ceilings

| Metric | Working value |
| --- | --- |
| GDP | **~$5.5T** |
| Defense baseline | **~$130B/year (~2.4% GDP)** |
| Modernization Act add-on | **~+$40B/year** ring-fenced ~15 years (procurement + industrial capex) |
| Combined "new kit + factories" pot | On the order of **tens of billions PD/year** after personnel/O&M — large, not infinite |

Programs still compete. A rough cost row in `data/costs.csv` should be able to look these ceilings in the eye.

## Legacy industry (what exists before the jump)

- **Can build today:** small arms & ammo (limited surge), trucks, patrol craft / some surface combatants slowly, strong software/drone startups, commercial ship repair.
- **Can overhaul / partially build:** armor, artillery, larger surface combatants, airframes in MRO.
- **License / import for the jump:** modern fighters, high-end SAM seekers, submarine combat systems, many microelectronics, jet engines.

## Materials risks (light)

Propellant precursors, advanced semiconductors, turbine hot sections — usual import chokepoints. See `industry/README.md`. Prefer domestic capacity for high-consumption items (ammo, drones, vehicles, rifles).

## Trade

Two-ocean access helps, but both West Ocean and East Gulf approaches can be pressured in a Korvath crisis. Stockpiles still matter for the first months alone.
